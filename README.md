## 💭 What I Observed

After taking a long break from coding, I realized that I still remember most of the Java syntax. The logic came back faster than I expected, but I also noticed that I was a little slow while writing code.

I found myself thinking more before typing, which wasn't the case when I used to code regularly.

---

## 😅 Challenges I Faced

The first challenge wasn't writing the `Student` class—it was deciding how to organize the program.

Initially, I was confused about whether the `main()` method should be inside the `Student` class or whether there should be a separate `Main` class.

That made me realize I need to revisit Java project structure and understand when to separate responsibilities into different classes.

Another small challenge was remembering Java naming conventions and writing cleaner, more readable code instead of just making it work.

---

## 💡 What I Learned Today

* Constructors are used to initialize objects with valid data.
* Objects can interact with other objects using methods like `isSameBranch(Student otherStudent)`.
* Methods should belong to the class that owns the behaviour.
* Writing code is different from writing clean, maintainable code.
